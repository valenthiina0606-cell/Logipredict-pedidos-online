## Contexto y justificación
Este proyecto integra los conceptos del curso aplicados a un escenario de logística y comercio electrónico utilizando el dataset **E-Commerce Shipping Data (`Train.csv`)**, con 10,999 registros de envíos y variables como costo del producto, peso en gramos, descuentos, llamadas a soporte, calificación del cliente y puntualidad en la entrega.
